# Kukke Shree Travels Website

Static HTML/CSS website for GitHub Pages.

## Publish Notes

1. Upload all files to a GitHub repository.
2. Enable GitHub Pages from the repository settings.
3. After you know the live website URL, replace `https://example.github.io/` in `sitemap.xml` with the final GitHub Pages URL.
4. Submit the final `sitemap.xml` URL in Google Search Console.
